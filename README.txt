CONNECTION QUEST — CHROMEBOOK + GOOGLE SITES SETUP

FILES
index.html — the complete interactive game. No dependencies, fees, or student sign-in.

PUBLISH FOR FREE WITH GITHUB PAGES (teacher account required)
1. On a teacher computer, sign in at https://github.com (use a personal account if district policy allows; never upload student data).
2. Click + > New repository. Name it thinking-skills-arcade. Select PUBLIC and Create repository.
3. Select Add file > Upload files. Upload index.html from this folder and commit the changes.
4. Open repository Settings > Pages. Under Build and deployment, select Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for GitHub Pages to finish publishing. Your site URL will be https://YOUR-USERNAME.github.io/thinking-skills-arcade/
6. Open that URL in Chrome to verify it loads. In Google Sites, choose Insert > Embed > By URL, paste the published URL, then Insert. Resize the embedded area and Publish your Google Site.
7. If your district blocks GitHub Pages or embeds, ask IT to approve the URL/domain. You can also link to the game from Google Sites using a button rather than embedding it.

TEACHER STUDIO
- Create four groups with four UNIQUE terms each, a category, and a reason.
- Save: stores on the CURRENT browser only. It does not sync to student Chromebooks.
- Export: download a JSON backup of your custom topics.
- Share: select your custom topic in the topic dropdown, go to Teacher Studio, then Copy topic link. This puts the topic into the URL so students can play it on another device. This feature requires that the game is already hosted.
- Import: restore a JSON topic pack into the browser where you are working.
- Shared topic links are best distributed via Google Classroom or a Google Sites button. Note: Google Sites URL embeds may not preserve URL fragments in all setups; a normal button link is more reliable for custom-topic links.
- For permanent school-wide custom topic sets, update the built-in data in index.html or ask for a version with a shared content source.

PRIVACY AND LIMITATIONS
- No external libraries, accounts, ads, analytics, or server storage.
- The game is not access-controlled. Anyone with the published URL can view it.
- Student explanations are not submitted or collected. Students should show the teacher their screen if the teacher wants to review responses.
- GitHub Pages requires a public repository on free accounts; do not put student names, grades, or sensitive data in topic files.
- No live multiplayer or automatic gradebook integration.
- If GitHub Pages is blocked by school policy, consult IT before using an alternative host.
